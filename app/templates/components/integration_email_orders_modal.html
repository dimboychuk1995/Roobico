Parts orders from email

Order confirmations and invoices from your vendors turn into parts orders marked Not confirmed; you confirm or reject them on the Parts Orders tab. Everything else in the mail is ignored.

Set up auto-forwarding once in the mailbox where vendors write you, or ask vendors to CC this address.

Forwarding the whole mailbox is fine — the AI ignores what is not an order. Some services send a confirmation code or link to the new forwarding address first — it shows up under Recent emails below: open it (View) to read the code.

Gmail / Google Workspace
  1. Gmail → gear → See all settings → Forwarding and POP/IMAP.
  2. Add a forwarding address → paste the address → Next.
  3. Gmail sends a confirmation: the code is in the email subject under Recent emails. Enter it, choose Forward a copy of incoming mail and keep Gmail's copy in the Inbox.
  4. Only vendor mail: Filters and Blocked Addresses → Create a new filter → From: vendor addresses (with OR) → Forward it to → the address.
Workspace: if forwarding is greyed out, the Google Admin must allow "Automatic forwarding" (Apps → Gmail → End user access).
Outlook.com / Microsoft 365
  1. Outlook on the web → gear → Mail → Forwarding.
  2. Enable forwarding → paste the address → tick Keep a copy → Save.
  3. Only vendor mail: Rules → Add new rule → From vendor → Forward to.
Microsoft 365 business: the admin may need to allow external forwarding.
Yahoo Mail
  1. Settings → More Settings → Mailboxes → your address → Forwarding.
  2. Enter the address → Verify; open the verification email under Recent emails and follow the link.
Auto-forwarding may require a paid Yahoo plan; alternative: ask vendors to CC the address.
iCloud Mail
  1. icloud.com → Mail → gear → Settings → General.
  2. Tick Forward my email to → paste the address → keep a copy → Done.
Zoho Mail
  1. Settings → Mail Accounts → your account → Forwarding → Add email address.
  2. Confirm with the code from the verification email (Recent emails → View).
GoDaddy / cPanel / hosting mailboxes
  1. Hosting panel → Email → Forwarders (cPanel) or Forwarding (GoDaddy).
  2. Add a forwarder from your mailbox to the address; keep a local copy if the option exists.
Apple Mail / Outlook desktop / phone
Apps forward only while open. Set forwarding on the web side of the account (see the provider above) so it works 24/7.
Vendors' portals (FleetPride, NAPA, ...)
Most portals allow several notification emails per account. Add the address as an extra recipient for confirmations and invoices — no forwarding needed.
Test it: forward any vendor invoice you already have to the address. Within a minute it appears under Recent emails and, if it is an order, on the Parts Orders tab with the Not confirmed badge.

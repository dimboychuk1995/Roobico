Email orders inbox

Every location gets its own mailbox that only the AI reads. Forward the location's vendor mail there (or give the address to vendors as a CC). Each incoming email is checked: order confirmations, invoices and packing slips become parts orders with the Not confirmed flag; everything else stays in the history below as Ignored. Nothing is received, paid or counted in vendor balances until a person confirms the order on the Parts Orders tab.

Lost it to spammers? — the old one stops working immediately (update your forwarding rule).

Two ways. A. Forward everything from the mailbox where vendors write you — the AI ignores what is not an order, so forwarding the whole inbox is fine. B. Give the address to vendors and ask them to CC it on confirmations and invoices (or add it as a second contact email in their portal). Some services send a confirmation code or link to the new forwarding address first — it lands in the history below: open the email (View) to read it.

Gmail / Google Workspace
  1. Gmail → gear → See all settings → Forwarding and POP/IMAP.
  2. Add a forwarding address → paste the address above → Next.
  3. Gmail sends a confirmation: the code is in the email subject in the history below. Enter it and choose Forward a copy of incoming mail (keep Gmail's copy in the Inbox).
  4. To forward only vendor mail instead: Filters and Blocked Addresses → Create a new filter → From: vendor addresses (separate with OR) → Forward it to → the address above.
Workspace: if forwarding is greyed out, the Google Admin must allow "Automatic forwarding" (Apps → Gmail → End user access).
Outlook.com / Microsoft 365
  1. Outlook on the web → gear → Mail → Forwarding.
  2. Enable forwarding → paste the address → tick Keep a copy of forwarded messages → Save.
  3. Only vendor mail: Mail → Rules → Add new rule → Condition From vendor → Action Forward to → the address.
Microsoft 365 business: the admin may need to allow external forwarding (Exchange admin → Mail flow → Remote domains, or Defender outbound spam policy).
Yahoo Mail
  1. Settings → More Settings → Mailboxes → your address → Forwarding.
  2. Enter the address → Verify; open the verification email in the history below (View) and follow the link.
Automatic forwarding in Yahoo may require a paid plan; alternative: ask vendors to CC the address.
iCloud Mail
  1. icloud.com → Mail → gear → Settings → General.
  2. Tick Forward my email to → paste the address → keep a copy → Done.
  3. Only vendor mail: Rules → Add a Rule → "is from" vendor → Forward to.
Zoho Mail
  1. Settings → Mail Accounts → your account → Forwarding → Add email address.
  2. Confirm with the code from the verification email (history below, View).
GoDaddy / cPanel / hosting mailboxes
  1. Hosting panel → Email → Forwarders (cPanel) or Forwarding (GoDaddy Workspace / Microsoft 365 from GoDaddy).
  2. Add a forwarder from your mailbox to the address above; keep a local copy if the option exists.
Apple Mail / Outlook desktop app / phone
Desktop and phone apps forward only while the app is open. Set forwarding on the web side of the account (see the provider above) so it works 24/7.
Vendors' portals (FleetPride, NAPA, Vander Haag's, ...)
Most vendor portals allow several notification emails per account. Add the address above as an extra recipient for order confirmations and invoices — then no forwarding is needed at all.
Test it: forward any vendor invoice you already have to the address. Within a minute it appears in the history below and — if it is an order — on the Parts Orders tab with the Not confirmed badge.

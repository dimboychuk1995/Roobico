  • The order dialog step by step: vendor, date, lines, cores, non-inventory amounts.
  • Where the default price comes from.
  • What happens after Create order.
{% endcall %}

Three ways an order appears: typed in by hand ({{ ui("Order") }} button), scanned from a vendor invoice (AI Order Reader), or created automatically from the location's email inbox. This lesson covers the first; the others follow in this module. One order = one vendor. Creating needs {{ perm("parts_orders.create", "Create parts orders") }}.

{% call step(1, "Open the dialog") %}

Parts → {{ ui("Order") }} (or the dashboard quick action Create PO, or the Parts orders block on a work order).

{{ shot("parts-order-modal", "Order parts (one vendor) — empty.", "md") }} {% endcall %} {% call step(2, "Vendor and date") %}

Pick the Vendor (searchable; only active vendors). Order Date defaults to today.

{% endcall %} {% call step(3, "Find part") %}

Type 2+ characters of a part number or description and click a result to add a line. Lines have Part #, Description, In Stock, Qty, Price and Total. Adding the same part again increases Qty. The search also finds inactive parts (grey Inactive badge) — adding one reactivates it when the order is created.

{{ shot("parts-order-modal-filled", "Vendor picked and part lines added.", "md") }} {% endcall %} {% call step(4, "Price, core charge") %}

The price defaults to the part's Last price — what you paid on the latest order with it (results show “Last $X · Avg $Y”); only a never-ordered part defaults to its average cost. If the part has a core charge, a toggle + Core $X appears (on by default) and adds qty × core charge to the total.

{% endcall %} {% call step(5, "Non inventory amount") %}

Spending that is not parts and does not touch stock: types shop supply / tools / utilities / payment to another service, plus description and amount. An order may consist of non-inventory lines only.

{% endcall %} {% call step(6, "Create order") %}

The order gets a sequential Order # (starts at 1000), status ordered and payment status Unpaid. The dialog then offers {{ ui("Receive") }} and {{ ui("Pay") }} without closing.

{{ shot("parts-order-created", "Right after Create order.", "md") }} {% endcall %} {% call note("Vendor invoice number") %} The vendor's own invoice number is not entered here — it goes into Vendor Bill when you receive the order. {% endcall %} {% call tip("Side effects on the part") %} Creating (or saving) an order updates the part's Last price and sets its Vendor to this order's vendor — the Vendor column always shows where you bought the part last. {% endcall %}

On a parts order that is received or fully paid, click {{ ui("Return") }} (needs {{ perm("parts_orders.receive", "Receive / un-receive parts orders") }}). Enter quantities per line (capped by what is still returnable) and an optional note — reason, RMA number.

{{ shot("parts-orders-tab", "Return is one of the row actions on the Parts Orders tab.") }} {% endcall %} {% call step(2, "The credit document") %}

A separate return document R-<number> is created with a Credit badge — it is a vendor credit, not a debt; payments cannot be applied to it. Returns subtract from purchase totals in the orders tab and reports and show up under Vendor credits on the Parts Orders Payments tab.

{% endcall %} {% call step(3, "Stock") %}

If the source order was received, the returned parts are deducted from stock (from the same locations); deleting the return puts them back.

{% endcall %}

Finding returns

The status filter on the Parts Orders tab has a Returns option — only return documents are shown and the footer totals sum just the returns (as negative amounts). Search and the date filter work as usual.

Paperwork

Every return row has a {{ ui("Files") }} button — attach the vendor's credit invoice or RMA paperwork there. These files belong to the return itself and are not shown on the original order.

{% call note("Cores are separate") %} Old cores go back through the Cores tab → Return, not through a parts return. See {{ lesson_link("parts/cores") }}. {% endcall %}

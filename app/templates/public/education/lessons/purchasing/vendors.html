Columns

Name, Phone, Email, Website (a short link such as fleetpride.com/login that opens in a new tab), Primary contact, Address, Balance (unpaid total across the vendor's orders — needs {{ perm("parts_orders.view", "View parts orders") }}) and Status. The search box searches every field including contacts; the status filter shows active, inactive or all vendors.

Add a vendor

{% call step(1, "Add Vendor") %}

{{ ui("Add Vendor") }} (needs {{ perm("vendors.create", "Create vendors") }}): Name (required), Website, Address with autocomplete, Notes and a Contacts block — several contacts, one always marked Main contact and used by default.

{{ shot("vendors-add-modal", "Create new vendor.", "md") }} {% endcall %} {% call step(2, "Website — just the address") %}

Type the website the way you say it: fleetpride.com or www.napaonline.com/login — https:// is added automatically and the list shows it without it. Text that is not a web address ("N/A", spaces, javascript:) is refused with "Enter a valid website, e.g. fleetpride.com"; an empty website is fine.

{% endcall %} {% call step(3, "Portal login (optional)") %}

If you order on the vendor's website, fill the Portal login section: Login and Password (Show checks what you typed). The password is stored encrypted. When editing later, the field says the password is saved — leave it blank to keep it, type a new one to replace it, or tick Remove saved password. The section is visible only with {{ perm("vendors.view_credentials", "View vendor portal logins & passwords") }}.

{% endcall %} {% call step(4, "Save") %}

The vendor is available in the order dialog and the part form right away.

{% endcall %}

Portal logins — find a password in seconds

Vendors → tab {{ ui("Portal logins") }} (next to "Vendors", needs {{ perm("vendors.view_credentials", "View vendor portal logins & passwords") }}): a compact table of active vendors with the Website link, the Login with a copy button and the Password as •••••••• with {{ ui("Show") }} and copy buttons. A shown password hides again after 30 seconds; copy puts it on the clipboard without showing it. Search finds a vendor by name, website or login; rows without a saved login show "—".

By default Owner, General manager, Manager and Parts manager have the permission; mechanics and viewers don't. A person who has it but cannot create or edit vendors opens Vendors straight on Portal logins — handy for a counter person who only needs to look passwords up.

{% call note("Every reveal is recorded") %} Each password Show — and Copy while the password is hidden — appears in Reports → Activity Journal as "Viewed portal password of …" (Action Viewed) — who, when, from where, never the password itself; copying the login is not recorded. Saving shows the login and the password only as set / changed / removed, never their values, so a Viewer who opens the journal does not see them. Logins and passwords never go into exports, the AI assistant or logs. In the mobile app the vendor screen has the same Portal login card: Show, long-press to copy. {% endcall %}

Vendor Orders

Click a vendor's name: the Vendor Orders popup lists their orders with a date filter and totals — Orders, Total Amount, Paid, Unpaid, Received, Not Received. There is no separate vendor page; this popup is it.

{{ shot("vendors-orders-modal", "Vendor Orders popup.", "md") }}

Deactivate = delete

{{ ui("Delete") }} deactivates the vendor (needs {{ perm("vendors.deactivate", "Deactivate vendors") }}): hidden from pickers, history stays; {{ ui("Restore") }} brings it back. Inactive vendors cannot be selected on new orders or parts. A vendor name that already exists (even inactive) cannot be created twice.

{% call tip("Vendors created by AI") %} The AI Order Reader and the email inbox create vendors automatically when an invoice names one you do not have. If that creates a duplicate, open the order, pick the right vendor and save — the auto-created one is deleted and the sender is remembered. See {{ lesson_link("purchasing/email-orders") }}. {% endcall %}

Columns

Name, Phone, Email, Website, Primary contact, Address, Balance (unpaid total across the vendor's orders — needs {{ perm("parts_orders.view", "View parts orders") }}) and Status. The search box searches every field including contacts; the status filter shows active, inactive or all vendors.

{{ ui("Add Vendor") }} (needs {{ perm("vendors.create", "Create vendors") }}): Name (required), Website, Address with autocomplete, Notes and a Contacts block — several contacts, one always marked Main contact and used by default.

{{ shot("vendors-add-modal", "Create new vendor.", "md") }} {% endcall %} {% call step(2, "Save") %}

Vendor Orders

Click a vendor's name: the Vendor Orders popup lists their orders with a date filter and totals — Orders, Total Amount, Paid, Unpaid, Received, Not Received. There is no separate vendor page; this popup is it.

{{ shot("vendors-orders-modal", "Vendor Orders popup.", "md") }}

Deactivate = delete

{{ ui("Delete") }} deactivates the vendor (needs {{ perm("vendors.deactivate", "Deactivate vendors") }}): hidden from pickers, history stays; {{ ui("Restore") }} brings it back. Inactive vendors cannot be selected on new orders or parts. A vendor name that already exists (even inactive) cannot be created twice.

{% call tip("Vendors created by AI") %} The AI Order Reader and the email inbox create vendors automatically when an invoice names one you do not have. If that creates a duplicate, open the order, pick the right vendor and save — the auto-created one is deleted and the sender is remembered. See {{ lesson_link("purchasing/email-orders") }}. {% endcall %}

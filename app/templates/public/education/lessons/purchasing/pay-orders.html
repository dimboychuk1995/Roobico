{% call step(1, "Pay") %}

{{ ui("Pay") }} on the order → Record parts order payment: Amount, Method (Cash / Card / Bank transfer / Check / Other), Payment Date, Notes, attachments for the receipt.

{{ shot("parts-order-pay-modal", "Record parts order payment.", "md") }} {% endcall %} {% call step(2, "Partial or full") %}

Partial payments are fine — the order becomes Partially Paid; overpaying above the order total is blocked. On received orders the payment date is always today.

{% endcall %} {% call step(3, "The payments ledger") %}

Parts → Parts Orders Payments lists all vendor payments with totals; a payment can be deleted there and the order balance re-syncs automatically. The Vendor credits section below lists parts returns and core returns — money vendors owe you back (informational, never applied to payments).

{{ shot("parts-orders-payments-tab", "Parts Orders Payments with Vendor credits.") }} {% endcall %}

Who you owe

  • Reports → Vendor Balances — per vendor: Orders, Total, Paid, Outstanding.
  • Reports → Parts Orders Summary — spending by type: Parts / Cores / Shop Supply / Tools / Utilities / Pmt to Svc.
  • Vendors list → Balance column, and the Vendor Orders popup.

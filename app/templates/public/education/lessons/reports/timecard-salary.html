How rows are computed

  • Salary employees: weekly salary amount × weeks in the period (days ÷ 7; a shorter range prorates fractionally). Pay type and amount are set in the user form (needs {{ perm("settings.manage_pay", "Edit employees' pay type & salary") }}).
  • Hourly employees: uAttend punches in the period × their hourly rate (set in Settings → Integrations; only employees ticked there appear).
  • uAttend people are auto-matched to Roobico users so nobody is counted twice: an employee matched to a salary user is folded into that row with a “↔ uAttend” badge; one matched to an hourly user keeps their own hourly row with the user's role and a “↔ Internal” badge.

Periods: This week / Last week / This month / Last month / This year / Custom. Banners explain when the uAttend integration is missing, disabled or erroring. The same payroll numbers feed General Revenue.

{% call note("Nobody can change their own pay") %} Even with the pay permission, a user cannot edit their own pay type or salary — an owner's pay is edited from another owner account, or not at all. {% endcall %}

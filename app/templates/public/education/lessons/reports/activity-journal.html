Reports → Activity Journal (needs {{ perm("reports.view_audit", "View audit journal") }}) — the complete history of who did what in the shop. Every change made through the web app, the mobile app, the customer portal or the email inbox lands here; reads / views are not logged. Passwords and tokens are masked everywhere.

{{ shot("report-activity-journal", "The Activity Journal with its filters.") }}

A row

  • When (shop time), Who (user and role, or Customer for portal actions, System for automatic ones).
  • Action — Created, Updated, Deleted, Status changed, Payment, Sent, Received, Returned, Activated / Deactivated, Signed in / out, Timer, Marked done, Confirmed, Transferred, Imported, Uploaded, Permissions changed, Settings changed, Access denied, Failed request.
  • Object — a link to the work order, unit, customer, part, parts order, vendor, user, role, appointment…
  • What happened — a plain sentence such as “WO #1042: status open → paid”.
{% call step(1, "Click a row to expand") %}

A Before / After table of every field that changed, extra details (amounts, quantities, recipients, files) and the technical trace (HTTP method and path, status code, IP, user id).

{{ shot("report-activity-journal-row", "An expanded entry with its details.") }} {% endcall %}

Filters

Free-text search (WO number, customer, part number, user name, any changed value), period presets or a custom range, user, object type, action, source (web / mobile / portal / system), location for multi-location tenants, and Show: everything, business events only or technical requests only.

{% call tip("Fastest path") %} Open the work order or customer and press {{ ui("History") }} — the journal opens filtered to that one record. {% endcall %} {{ shot("wo-history-button", "The History button on a work order.") }} {% call note("Attempts are visible too") %} Failed requests and access denials are journaled, so attempts to do something without permission show up here. {% endcall %}

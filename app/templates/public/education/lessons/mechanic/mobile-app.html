{% endcall %} {% call step(1, "Install and log in") %}

Install the Roobico app from the App Store (TestFlight during the beta). Log in with the same email and password as the web. You stay signed in permanently — closing or restarting the app does not log you out; access still ends immediately when a user is deactivated.

{{ mobile_shot("shot-mobile-dashboard.png", "The mobile dashboard for an office user.") }} {% endcall %} {% call step(2, "Bottom tabs") %}
  • Dashboard — outstanding balance, revenue / paid / unpaid, work order count, labor, parts and parts-order stats per period.
  • Work Orders — list + Payments + Estimates segments, create / edit, payments, authorization, email PDF, AI scan of a paper work order (managers).
  • Customers — list / search, customer and unit pages, forms.
  • Parts — Stock (with cross references ⇆), Orders (incl. AI invoice scan), Counts (stocktakes).
  • More — global Search, Vendors, Calendar, Reports, Settings with Active shop switching and account info.

Tabs and buttons follow permissions exactly like the web — a mechanic sees only Work Orders + More; the server checks every request.

Where tracked time goes

  • Work order — the office sees a red ● working marker live and the summed tracked time per job; hours of mechanic-created jobs auto-fill from it ({{ lesson_link("work-orders/labor-blocks") }}).
  • Work Orders list — the green ● names line and the In Work group.
  • Calendar — one block per mechanic per session, exactly when the timer ran ({{ lesson_link("calendar/wo-on-calendar") }}).
  • Reports — Mechanic Hours (Tracked vs Billed), the dashboard hours chart, and payroll where hourly pay is based on tracked work.
  • Push — the first timer on a work order sends “WO #… in work” to office phones.
{% call tip("Forgot to stop the timer?") %} A manager fixes it on the web work order: the pencil next to the Mechanics line opens the sessions — change the duration or delete the session. Everything recalculates. See {{ lesson_link("work-orders/assign-mechanics") }}. {% endcall %}

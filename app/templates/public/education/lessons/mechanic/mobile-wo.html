For mechanics

{% call step(1, "Open a work order") %}

Work Orders tab → tap the job. The Current mileage window appears first — confirm or correct the odometer. There is no separate view screen: opening always lands in the editable view.

{{ shot("mech-mileage-modal", "The mileage prompt (web version shown; the app asks the same).", "sm") }} {% endcall %} {% call step(2, "Edit — it autosaves") %}

Every change (description, parts, mileage…) autosaves as In Progress about a second after the last edit (“Changes are saved automatically”). The only explicit button is {{ ui("Done — ready for review") }}.

{% endcall %} {% call step(3, "Job photos") %}

Every job card has its own attachments block (camera or gallery) — files are tied to that job; the work-order-level Attachments block is separate. Mechanics can view and upload; deleting needs the Delete attachments permission.

{% endcall %} {% call step(4, "Send for approval") %}

{{ ui("Send job for approval") }} on a job card, or {{ ui("Send work order for approval") }} at the bottom — the same customer authorization flow managers use from the web.

{% endcall %} {% call step(5, "New work order") %}

The + button: pick customer and unit, or {{ ui("Scan VIN") }} ({{ lesson_link("mechanic/vin-scan") }}), confirm the mileage, add jobs and parts.

{{ mobile_shot("shot-mobile-wo.png", "The Work Orders tab on the phone.") }} {% endcall %}

For managers

  • Create and edit work orders, record payments, send for authorization, email the PDF, delete.
  • AI scan — photograph a paper work order and AI fills jobs and parts; AI edit polishes the issue description.
  • See Tracked per job — the summed clocked time of all mechanics who worked on it, with a per-person breakdown.
  • {{ ui("Confirm work order") }} after the Mechanic done badge, {{ ui("Mark unpaid") }} and the other status actions, each behind its permission.
{% call note("The date rule applies here too") %} Every autosave that actually changed jobs, parts or mileage, and the first press of Done, moves the work order date to that day. Merely opening does not. {% endcall %}

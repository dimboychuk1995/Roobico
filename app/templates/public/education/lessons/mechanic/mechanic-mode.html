Who gets mechanic mode

Any user whose role lacks {{ perm("work_orders.view_costs", "View part costs inside WO") }} — the default Mechanic and Senior mechanic roles. Such users are redirected from the normal Work Orders pages to a simplified no-price interface (web: /mechanic/work_orders; the mobile app shows the same mode automatically).

{{ shot("mech-wo-list-desktop", "The mechanic work order list in a desktop browser.") }}

What a mechanic sees

  • Job list — search, an In work now section with everyone's running timers, a “My timer running” marker, a + button for a new work order. Only In Progress work orders are listed — active work, including ones marked Done awaiting review. Completed, paid and estimate work orders never appear (past work is available through the unit's history).
  • No money anywhere — no prices, costs, totals or balances; stripped server-side, even for managers who open the mechanic pages.
  • Create / edit work orders — pick customer and unit (or create a unit), add jobs (“What was done…”), add parts by search (quantities only; a non-catalog entry becomes “one-time part — manager fills the price”), apply presets.
  • Job timers, job photos, unit history, Send for approval.

What a mechanic cannot do

  • Set a status: every mechanic save is In Progress; only a user who sees prices completes, pays or reopens a work order. Paid work orders are locked entirely; confirmed ones are locked for mechanics until the manager cancels the confirmation.
  • Delete existing jobs (manager-only). Prices, hours and rates the office entered are preserved when a mechanic edits.
  • Open estimates — quotes live in the office interface only.
{% call note("Jobs get a rate automatically") %} A job a mechanic adds without a preset gets the shop's “standard” labor rate (or the first active rate) on the server, so the office never sees a $0 labor line. {% endcall %} {% call tip("Senior mechanic") %} The Senior mechanic role additionally sees customers, units and the parts catalog — still without a single dollar amount — and the Mechanic Hours report. {% endcall %}

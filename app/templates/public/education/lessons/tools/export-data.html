Moving data to another shop

Export columns match the import fields, so a file exported from one shop imports into another with automatic column mapping — except units, which are imported per customer: split a whole-shop units export by the Customer Name column and import one file per customer.

{% call tip("Backups") %} Roobico keeps its own daily backups, but an occasional export of customers, units and parts is a convenient offline copy for your records. {% endcall %}

Where to start one

  • Work order → Create / Save dropdown → {{ ui("Create Annual Inspection") }} — prefilled with the unit's VIN and the customer as carrier.
  • Unit page → {{ ui("Annual Inspection") }} in the header (or {{ ui("Inspection") }} next to a unit on the customer's Units tab).
  • Perks → Annual Inspection → {{ ui("New Inspection") }} — for any vehicle, even one not in the system: type the VIN, pick the type, enter the customer name by hand.

The dialog

{% call step(1, "Header fields") %}

Carrier, address, inspector, agency, date, the qualified inspector check and an optional Report Number (your own numbering; auto-generated when left empty).

{{ shot("wo-annual-inspection-modal", "The Annual Vehicle Inspection dialog with the checklist and live preview.") }} {% endcall %} {% call step(2, "Vehicle type") %}

Picking a type applies its OK / NA preset automatically (e.g. Semi Trailer marks steering, exhaust, coupling as N/A). Adjust any item afterwards.

{% endcall %} {% call step(3, "The checklist") %}

Every component (Brake System, Coupling Devices, … Windshield Wipers) starts as OK; switch an item to NR (needs repair — a repaired-date field appears) or NA. {{ ui("Mark all OK") }} / {{ ui("Clear") }} set the whole list; Clear prints an empty form to fill by hand.

{{ shot("perks-inspection-modal", "New Inspection from Perks.", "md") }} {% endcall %} {% call step(4, "Save") %}

The PDF downloads with the marks: OK items get a check in the OK column, needs-repair items an X plus the repaired date, N/A items a mark in the third column.

{% endcall %}

History and validity

Inspections are kept as history per unit — a new one does not erase the previous. Each is valid 12 months: the unit page shows the latest with its Valid until date (yellow within 30 days of expiry, red when expired), the full history with PDFs, and Delete buttons (needs {{ perm("work_orders.delete", "Delete work orders") }}).

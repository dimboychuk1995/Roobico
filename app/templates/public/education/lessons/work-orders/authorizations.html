  • Sending the whole work order or a single job for approval.

{% endcall %} {% call step(1, "Choose the scope") %}

Whole work order: {{ ui("✉ Send for Authorization") }} at the top of the labor section. One job only: ⋮ on that labor block → {{ ui("Send for Authorization") }}. Sending needs only {{ perm("work_orders.create", "Create work orders") }}.

{{ shot("wo-labor-menu", "Send for Authorization for a single job in the ⋮ menu.") }} {% endcall %} {% call step(2, "Pick recipients") %}

The email dialog lists the customer's contacts (main contact preselected). Add a new address on the fly if needed. Send.

{{ shot("wo-send-authorization-modal", "Choosing recipients for the authorization request.", "md") }} {% endcall %} {% call step(3, "The customer approves or declines") %}

The customer receives an email with the PDF and a link to a public page with {{ ui("✓ Approve") }} / {{ ui("✕ Decline") }} buttons and an optional comment. No login is required.

{% endcall %} {% call step(4, "See the result") %}

A green ✓ Authorized or red ✕ Declined badge appears on the work order (and on the labor block, for single-job requests); the comment is in the tooltip. The customer portal lists the full history under Authorizations.

{% endcall %} {% call note("Estimates too") %} Estimates can be sent for approval exactly the same way — same email, same badge. Approval does not change the status or touch inventory; it is the customer's sign-off on the quote. Convert to a work order when you are ready. {% endcall %} {% call tip("From the phone") %} Mechanics can send a single job or the whole work order for approval from the mobile app (“Send job for approval” / “Send work order for approval”).

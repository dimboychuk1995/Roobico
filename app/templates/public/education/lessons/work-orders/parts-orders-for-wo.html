In the office interface (needs {{ perm("work_orders.view_costs", "View part costs inside WO") }}) the Customer & Unit section has a discreet {{ ui("Parts orders") }} button under the unit row — on existing work orders and on the create screen alike.

{{ shot("wo-parts-orders-block", "The Parts orders block expanded under the unit.") }} {% call step(1, "Create parts order") %}

Click {{ ui("Create parts order") }}. It opens the same order dialog as Parts → Order: vendor search, order date, part search with cross references and stock, core charges, non-inventory amounts, the running total and the AI Order Reader. The only difference: the order is linked to this work order automatically.

{{ shot("parts-order-modal", "The order dialog — identical to the one on the Parts page.", "md") }} {% endcall %} {% call step(2, "Before the work order is saved") %}

Orders can be created on the create screen too: they attach to the page and link to the work order the moment you press Create Work Order.

{% endcall %} {% call step(3, "Receive and pay right here") %}

Each linked order shows its status (ordered / received), payment status (unpaid / partial / paid), total and balance. {{ ui("Receive") }} asks for the vendor bill and stock locations, then updates stock; {{ ui("Pay") }} records a payment with attachments; the order number or {{ ui("Open") }} opens the full dialog.

{% endcall %}

Badges in both lists

The order appears on Parts → Parts Orders like any other, marked with a WO # badge that links back; the work orders table shows mirror PO # badges on rows with linked orders — click one to open that order.

Usage check

Once the work order is accepted (a real work order, not an estimate and not an unsaved page) each order item becomes a chip: green when the work order uses that many of the part, yellow when only part of the ordered quantity is on it (e.g. “2/3”), red when the part is not on the work order at all. A warning box lists everything ordered for this job but not used in it — so nothing bought for a job is forgotten on a shelf. While the work order is still an estimate the chips stay neutral.

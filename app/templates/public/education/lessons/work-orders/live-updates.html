The list is live

Every few seconds the Work Orders list checks the server and reloads itself when anything changed: a mechanic starts or stops a timer (the green ● working names and the In Work group update), saves a work order or marks it Done, or someone creates, edits, pays or deletes a work order from another computer. Your filters, page, active tab and scroll position are preserved. The reload politely waits if you are typing in a filter field or have a dialog (e.g. payment) open, and resumes when you finish.

The work order page is live

  • Running timers show up live. When a mechanic starts a job timer, a red ● working indicator with their name appears on that job's Mechanics line within seconds, and tracked time keeps accumulating on screen.
  • Changes reload the page. When a mechanic saves, marks Done, or a timer changes the status / hours, the page reloads by itself to show fresh jobs, parts and totals (scroll position preserved). Same when another manager updates or pays it elsewhere.
  • You are protected while editing. In Edit (or Confirm) mode the page does not reload under you — a warning toast tells you the work order was just updated so you can refresh before saving. Saving without refreshing may overwrite the mechanic's changes, since a save writes the whole job list.

Recording and deleting payments needs {{ perm("work_orders.manage_payments", "Manage payments") }}.

{% call step(1, "Open Record Payment") %}

On the work order page click {{ ui("Paid") }}; on the list click {{ ui("Pay") }} in the row. The dialog shows Invoice Total, Already Paid and Remaining Balance, with the amount pre-filled with the balance.

{{ shot("wo-payment-modal", "Record Payment from the work order page.", "md") }} {% endcall %} {% call step(2, "Amount and method") %}

Methods: Cash, Check, Credit Card, ACH, Other. Partial payments are fine — enter a smaller amount and the balance stays open; overpaying is blocked. Set the payment date and notes (check number, reference).

{{ shot("wo-pay-modal-list", "Record Payment from the list.", "md") }} {% endcall %} {% call step(3, "Attachments and receipt") %}

Attach a check photo or a card slip; the files belong to this payment. Tick the receipt option to email a payment receipt to the customer's contacts.

{% endcall %} {% call step(4, "Status") %}

When the remaining balance reaches $0 the work order becomes Paid and locks. Partial payments leave it Open with a reduced balance.

{% endcall %}

Where to see payments

  • Work Orders → Payments tab — every payment with search, date filter and totals.
  • Customer page → Payments tab — one customer's payments; delete possible.
  • Reports → Payments Summary — money received per customer and period.
{{ shot("wo-list-payments-tab", "The Payments tab of the Work Orders list.") }} {% call warn("Deleting payments") %} Deleting a payment reopens the balance (and un-pays a Paid work order). Reverting a Paid work order to Open or In Progress deletes all its payments — see {{ lesson_link("work-orders/statuses") }}. {% endcall %} {% call note("No deposits or credits") %} Recording more than the balance is blocked and there is no deposit / credit feature. For one check covering several invoices use {{ lesson_link("work-orders/bulk-payment") }}. {% endcall %}

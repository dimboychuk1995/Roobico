Sidebar → {{ ui("Work Orders") }}. A work order (WO) is the central document of a repair job; its number doubles as the invoice number (numbering starts at 1000, per shop).

Filters

Search by any field, the paid-status dropdown (All / Paid / Unpaid / In Progress) and date presets from Today to All Time (default This Month) filtering by the work order date. {{ ui("Reset") }} clears everything.

Status badges and mechanic activity

  • Paid (green), In Progress (blue), Open / Unpaid (yellow).
  • A green ● names line — mechanics with a running job timer on this work order right now; grey ● — taken but idle; green ✓ Name — this mechanic already pressed Done.
  • Mechanic done — every mechanic who worked on it pressed Done; the work order stays In Progress until you complete it.
  • Unassigned labor (red) — a labor line with a description, hours or parts has no mechanic yet. Open the work order and assign someone in that block. Never shown on paid work orders.
  • Confirmed — a manager confirmed the mechanic's work from the mobile app; the work order is locked for mechanics until the confirmation is cancelled.

The In Work group

Work orders that mechanics have taken but not marked done are grouped at the top under In Work · taken by mechanics, not marked done yet. This group ignores the date filter — whatever range you pick, everything currently on the shop floor is shown (search and the paid-status dropdown still apply). Each work order appears once. Note the footer totals still follow the selected date range.

{% call tip("The list is live") %} No manual refresh needed. Every few seconds the page checks the server and reloads itself when a mechanic starts or stops a timer, saves or marks Done, or when someone pays, edits, creates or deletes a work order elsewhere. Your filters, page and scroll position are preserved, and the reload waits politely while you type in a filter or have a dialog open. See {{ lesson_link("work-orders/live-updates") }}. {% endcall %}

Payments and Estimates tabs

Payments lists every payment recorded on any work order with its own search and date filter; the totals row sums exactly the filtered payments. Estimates lists all quotes — they are hidden from the main tab and its totals; Edit opens the estimate.

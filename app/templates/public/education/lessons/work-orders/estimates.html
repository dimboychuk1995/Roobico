{% endcall %} {% call step(1, "Create the estimate") %}

Fill the work order page as usual (customer, unit, jobs, parts), then open the dropdown next to {{ ui("Create Work Order") }} and choose {{ ui("Save as Estimate") }}.

{{ shot("wo-create-dropdown", "Save as Estimate in the Create dropdown.") }} {% endcall %} {% call step(2, "Where it lives") %}

Estimates sit on the Estimates tab of the Work Orders list (and the customer's Estimates tab). They are hidden from the main tab and its totals, take no parts from inventory, cannot receive payments and are edited only in the office web interface — mechanics and the mobile editor cannot open them.

{{ shot("wo-list-estimates-tab", "The Estimates tab.") }} {% endcall %} {% call step(3, "Send it to the customer") %}

An open estimate shows an Estimate badge on its page. {{ ui("Download PDF") }} produces the same document titled Estimate (file Estimate-<number>.pdf). {{ ui("Send for Authorization") }} works exactly like on a work order — email with the PDF and Approve / Decline buttons; a green ✓ Authorized badge appears when the customer approves. Approval does not change the status or touch inventory.

{{ shot("wo-estimate-page", "An estimate page with the Estimate badge.") }} {% endcall %} {% call step(4, "Convert when the job is approved") %}

Open the estimate → Save dropdown → {{ ui("Convert to Work Order") }}. It becomes a normal open work order; at that moment all its parts are deducted from stock and core tracking starts. The PDF title switches back to Work Order.

{{ shot("wo-save-dropdown", "Convert to Work Order in the Save dropdown.") }} {% endcall %}

The reverse

On a normal unpaid work order the Save dropdown has {{ ui("Save as Estimate") }}: the work order becomes an estimate, all its parts return to inventory and pending cores are removed. A work order with recorded payments cannot become an estimate — delete the payments first. Convert back and forth as many times as needed; stock moves accordingly each time.

{% call tip("A plain Save keeps it an estimate") %} Editing an estimate and pressing Save does not convert it. Only Convert to Work Order does. {% endcall %}

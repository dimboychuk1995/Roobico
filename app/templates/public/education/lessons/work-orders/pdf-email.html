Download PDF

{{ ui("Download PDF") }} on the work order page or the list (needs {{ perm("work_orders.export_pdf", "Export PDF") }}) produces WorkOrder-<number>.pdf. For an estimate the same document is titled Estimate. The layout — logo, colors, which fields print, footer text — is configured in Settings → PDF Design ({{ lesson_link("settings/pdf-design") }}). If a labor line has a Described Issue, it prints under the description as “Reported issue: …”.

Email Work Order

{% call step(1, "Open the dialog") %}

Click {{ ui("Email Work Order") }} (needs {{ perm("work_orders.send_to_customer", "Send to customer") }}). The dialog lists the customer's saved contacts with the main contact preselected.

{{ shot("wo-email-modal", "The Send Email dialog with the customer's contacts.", "md") }} {% endcall %} {% call step(2, "Pick or add recipients") %}

Tick the contacts to send to. Need another address? Add it on the fly — it shows a green New badge and can be saved to the customer card. The PDF is attached and the email includes the customer's portal link.

{% endcall %} {% call step(3, "Send") %}

The email goes out from Roobico; the Activity Journal records who sent what and to whom.

{% endcall %}

Managing contacts in the dialog

Each saved contact in the recipients list has a pencil (edit name / email / phone) and a trash icon (delete the contact from the customer, after an “are you sure” prompt). Changes save to the customer card immediately, exactly as if you edited them on the Customers page, and apply to all email dialogs (work order, payment receipt, authorization). Deleting the main contact promotes the next one. The icons are controlled by {{ perm("work_orders.manage_email_contacts", "Edit / delete customer contacts in email dialogs") }} — on for every role by default; switch it off for a role to make the list read-only (adding a new recipient still works).

{% call tip("Receipts") %} A payment receipt email is offered when you record a payment — same contacts dialog. See {{ lesson_link("work-orders/payments") }}. {% endcall %}

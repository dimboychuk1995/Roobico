  • One check (or transfer) that covers several invoices of the same customer.
  • Auto-Distribute across the oldest unpaid work orders.
{% endcall %} {% call step(1, "Open Bulk Payment") %}

Work Orders → {{ ui("Bulk Payment") }} in the header (needs {{ perm("work_orders.manage_payments", "Manage payments") }}).

{{ shot("wo-bulk-payment-modal", "The Bulk Payment dialog.", "md") }} {% endcall %} {% call step(2, "Pick the customer and enter the amount") %}

Select the customer — their unpaid work orders load with balances. Enter the amount received, the method, date and notes.

{% endcall %} {% call step(3, "Auto-Distribute") %}

Click {{ ui("Auto-Distribute") }}: the money is spread across the oldest unpaid invoices first. Adjust the per-work-order amounts by hand if the customer paid specific invoices; the summary shows how much is allocated and any leftover.

{% endcall %} {% call step(4, "Record") %}

{{ ui("Record Payments") }} creates one payment per work order. Fully covered work orders turn Paid; a partially covered one keeps its reduced balance.

{% endcall %} {% call note("Leftover money") %} The dialog does not let you allocate more than the sum of balances, and there are no customer credits — if the check is larger than what is owed, record what is due and handle the difference outside Roobico. {% endcall %}

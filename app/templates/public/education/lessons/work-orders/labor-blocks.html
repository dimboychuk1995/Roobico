Each labor block is one job on the work order. Add more with {{ ui("+ Add Labor") }}; remove an empty one with {{ ui("Remove") }}.

{{ shot("wo-labor-block", "A labor block in edit mode.") }}

Fields

FieldBehaviour
Labor DescriptionWhat was done. Printed on the PDF; a Described Issue (⋮ menu) prints under it as “Reported issue”.
HoursBilled hours. For jobs mechanics created themselves, hours auto-fill from the tracked timer time and keep following it until someone types in Hours or Labor Total; jobs from a preset keep the preset's hours.
Labor RateDropdown of the shop's rates shown as “Name ($X/hr)”, preselected from the customer's Default Labor Rate. The hourly rate is snapshotted on save — changing a rate later never changes old work orders.
Labor TotalEditable override. If you type a manual total it wins; otherwise labor = hours × rate.
{% call note("Saving is not a manual edit") %} Simply saving the work order does not stop the auto-fill — only typing in Hours or Labor Total does. If a mechanic tracked more time while you had the page open, saving your other edits keeps their latest tracked hours. {% endcall %}

Mechanics line

Under the fields, the Mechanics: line shows who is assigned and how much time was tracked. {{ ui("Assign") }} opens the Assign Mechanics dialog; the pencil next to the tracked time edits timer sessions. Both are covered in {{ lesson_link("work-orders/assign-mechanics") }}.

Shop supply

Shop supply is a percentage of labor (default 5%, set in Settings → Work Order Settings). It appears as an editable Shop supply: $ field with a reset (↺) button and is part of the Labor total.

The block menu (⋮)

  • {{ ui("Add Preset") }} — insert a service template into this block ({{ lesson_link("work-orders/presets-on-wo") }}).
  • {{ ui("Describe Issue") }} — AI polishes or translates the issue text into professional English for the customer.
  • {{ ui("Send for Authorization") }} — ask the customer to approve this job only ({{ lesson_link("work-orders/authorizations") }}).

Attachments per job

{{ ui("Labor Attachments") }} under a block holds photos and files for that job only — separate from work-order-level attachments. Mechanics add job photos from the phone here.

{% call tip("Jobs added by mechanics") %} A job a mechanic adds without a preset gets the shop's “standard” labor rate (or the first active rate) automatically, so the office never sees a $0 labor line. Change the rate later as usual. {% endcall %}

Assign mechanics

{% call step(1, "Open the dialog") %}

In the labor block click {{ ui("Assign") }} (edit mode). The Assign Mechanics dialog lists active users with the Mechanic or Senior mechanic role.

{{ shot("wo-assign-mechanics-modal", "Assign Mechanics dialog.", "md") }} {% endcall %} {% call step(2, "Tick one or several") %}

One mechanic = 100%. Several mechanics = percentages split evenly, editable. This split drives the Mechanic Hours report (billed hours per mechanic) and the Unassigned-labor badge on the list.

{% endcall %} {% call step(3, "Save the work order") %}

Assignments are saved with the work order. A labor line with a description, hours or parts and no mechanic shows the red Unassigned labor badge on the list until someone is assigned (a line with tracked time belongs to whoever tracked it).

{% endcall %}

Tracked time

Mechanics run a timer per job from the mobile app or the web mechanic page. The Mechanics: line shows the summed tracked time of everyone who worked on the job (with a per-person breakdown when there was more than one), and the work order details page shows a red ● working marker live while a timer runs. Tracked hours auto-fill the billed Hours of jobs the mechanics created ({{ lesson_link("work-orders/labor-blocks") }}), appear on the Calendar as blocks, and feed the Mechanic Hours and Timecard reports.

Edit mechanic hours (the pencil)

Users with {{ perm("work_orders.edit_time_logs", "Edit mechanics' actual tracked hours") }} — owner and managers by default — see a small pencil next to the tracked-time summary. It opens the job's timer sessions: who, when started, how long.

{{ shot("wo-mechanic-hours-modal", "Mechanic hours: the job's timer sessions.", "md") }}
  • Change a session's duration (hours / minutes) — the mechanic forgot to stop the timer overnight.
  • Delete a wrong session — started by accident.
  • After saving, everything derived from time recalculates: the job's tracked Hours, the percentage split, work order totals and the payroll / Timecard reports. Edited sessions get an edited badge.
{% call warn("Two locks") %} A running session must be stopped before it can be edited, and paid work orders are locked — unpay first. {% endcall %}

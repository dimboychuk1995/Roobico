Parts → Stocktakes tab. Counting needs {{ perm("parts.adjust_stock", "Adjust part stock") }}. Stocktakes are numbered ST-1, ST-2, …

{{ shot("parts-stocktakes-tab", "The Stocktakes tab.") }} {% call step(1, "New Stocktake") %}

{{ ui("New Stocktake") }}: optional name, Location scope (default Whole warehouse, sub-locations included) and Category scope. The warehouse keeps working while you count.

{{ shot("parts-stocktake-create-modal", "Start a stocktake: name, location and category scope.", "sm") }} {% endcall %} {% call step(2, "Count") %}

The count screen lists every part in scope with Location, Part #, Description, Expected, Counted (+ Save), Variance, Value and Status. Filter by text or with the chips All / Pending / Counted / Discrepancies. Each counted quantity is compared to the system stock at the moment of counting; if stock moves after a line was counted it is flagged Recount. {{ ui("Add found part") }} adds a part found on a shelf that is missing from the list.

{{ shot("parts-stocktake-page", "The counting screen.") }} {% endcall %} {% call step(3, "Complete & apply") %}

{{ ui("Complete & apply") }} applies the variances as deltas. In the confirmation, tick Set uncounted lines to zero for a full inventory — everything you did not count in the scope is treated as not found; for a cycle count leave it unticked and uncounted lines stay untouched. {{ ui("Cancel") }} discards the stocktake.

{{ shot("parts-stocktake-complete-confirm", "The Complete & apply confirmation.", "sm") }} {% endcall %} {% call step(4, "What changed") %}

A completed stocktake shows a was → became table of every adjusted line in three groups: Quantity changed, Went to zero (counted 0 or auto-zeroed) and Found during count (system had 0, counting found stock). Each row shows Was, Became, the ± difference and its value at average cost; header badges give the shortage / overage totals.

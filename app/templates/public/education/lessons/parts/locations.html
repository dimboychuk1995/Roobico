The location tree

Built on Settings → Parts & Pricing, card Parts Locations: up to 4 levels, e.g. Warehouse › Rack › Shelf › Bin. Each part has one primary location (set in the part form), but stock can sit in several locations at once.

Stock by location

{% call step(1, "Open Locations on a part") %}

Parts list → row → {{ ui("Locations") }} (tracked parts only). The dialog lists per-location quantities.

{{ shot("parts-locations-modal", "Stock by location: quantities, Set qty and the transfer section.", "md") }} {% endcall %} {% call step(2, "Set qty — a manual correction") %}

Type the real quantity for a location and {{ ui("Set") }}. This changes the total and needs {{ perm("parts.edit_stock_qty", "Edit on-hand quantity directly") }}; without it the Set control is hidden.

{% endcall %} {% call step(3, "Transfer between locations") %}

From / To / Qty → {{ ui("Transfer") }}. Transfers never change the total and need only {{ perm("parts.adjust_stock", "Adjust part stock") }}.

{% endcall %}

Receiving into a location

When you receive a parts order you choose where each line goes (“Put received parts into:”) — default is the part's primary location, otherwise Unassigned. A location chosen there becomes the part's default if it had none.

{% call note("Deleting a location") %} A location cannot be deleted while it has sub-locations, is the primary location of a part, or still holds stock — transfer the stock out first. {% endcall %} {% call tip("Stocktake by location") %} Count one rack or one shelf at a time: a stocktake can be scoped to a location (sub-locations included).

{{ shot("parts-add-modal", "The Create new part dialog.", "md") }} {% endcall %} {% call step(2, "Identity") %}
  • Part number — the only required field. Unique within the shop (case-insensitive): a number that already exists is refused; if the message says the existing part is inactive, add it to a parts order instead of creating a copy.
  • Reference — alternative / OEM number. Description — free text.
  • Vendor, Category, Location (the primary storage location).
{% endcall %} {% call step(3, "Stock and cost") %}
  • In stock — the starting quantity. Afterwards stock changes only through orders, work orders, transfers, stocktakes and manual adjustments. Editing this number on an existing part is a manual override and needs {{ perm("parts.edit_stock_qty", "Edit on-hand quantity directly") }} (by default Owner, General manager, Manager).
  • Average cost — the weighted average of what is in stock, recalculated on every receiving: (old avg × old qty + received price × received qty) ÷ total qty. Example: 2 in stock at $100, you receive 2 at $200 → 4 at $150. If stock is zero / negative or the average is 0, the received price simply becomes the average. Work orders never change it. You can type it by hand here.
  • Last price — read-only: the price on the latest parts order with this part; it pre-fills the price when you order again.
{% endcall %} {% call step(4, "Toggles") %}
  • This part has selling price → a fixed Selling price that overrides the pricing scale (unless the customer has “Override part selling price”).
  • Do not track inventory for this part — usable on work orders and orders, but stock is never adjusted (turning it on zeroes stock and disables the core charge). For fluids, consumables, shop supplies.
  • This part has Core charge → Core cost, the refundable deposit per unit.
  • Add Misc charge for this part → a list of misc charges (description, price, taxable) added automatically whenever the part goes on a work order — an environmental fee on every filter, for example.

{% endcall %} {% call step(1, "Deactivate") %}

Parts list → row → {{ ui("Deactivate") }} (needs {{ perm("parts.delete", "Delete parts") }}). The part disappears from work order part search, the mobile app, stocktakes and the inventory totals. Nothing is deleted — history, stock quantity and locations stay on the part; if it still has stock the confirmation says so.

{{ shot("parts-deactivate-confirm", "The Deactivate confirmation.", "sm") }} {% endcall %} {% call step(2, "Find it later") %}

Switch the filter next to the search box to Inactive parts or All parts. Inactive parts carry a grey Inactive badge and have only the History button.

{{ shot("parts-list", "The status filter next to the search box.") }} {% endcall %} {% call step(3, "Bring it back — through a parts order") %}

There is no Restore button. In the order dialog the part search also finds inactive parts (marked Inactive): add the part to the order and click {{ ui("Create order") }} — the part is active again at that moment. The same happens when an inactive part is in an order you receive, save, or in an email order you confirm; the AI Order Reader matches inactive parts too.

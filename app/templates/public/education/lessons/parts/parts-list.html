Sidebar → {{ ui("Parts") }}. Tabs: Parts, Parts Orders, Parts Orders Payments, Cores, Cores Returns, Stocktakes. Header buttons: {{ ui("Order") }} (new parts order) and {{ ui("Add Part") }}. Categories, storage locations and pricing scales are configured on Settings → Parts & Pricing.

{{ shot("parts-list", "The Parts tab with the header buttons highlighted.") }}

Search and filter

“Search parts by any field…” matches part number, description, reference, stock, cost and also vendor, category and location names. The status filter offers Active parts (default), Inactive parts, All parts.

Columns

ColumnMeaning
Part #The part number; a ⇆ hint lists interchangeable numbers (cross references).
Description, ReferenceFree text and the alternative / OEM number.
In stockTotal on hand across locations.
Avg costWeighted average cost of what is in stock — recalculated on every receiving.
Last priceThe price on the latest parts order with this part (hover for the order #); the default price when you order it again.
VendorAlways the vendor of the latest parts order with this part — it switches automatically when you buy elsewhere.
Category, LocationLocation shows a per-location breakdown when stock is split (“Shelf A × 3, Shelf B × 1”); stock without a location is “Unassigned”.

Footer: Total inventory cost (Σ stock × avg cost) and Total core cost for the parts shown by the current filter.

Row actions

{{ ui("Cross refs") }}, {{ ui("History") }}, {{ ui("Locations") }} (tracked parts only), {{ ui("Edit") }} (needs {{ perm("parts.edit", "Edit parts") }}) and {{ ui("Deactivate") }} (needs {{ perm("parts.delete", "Delete parts") }}). {{ ui("Add Part") }} needs {{ perm("parts.create", "Create parts") }}; {{ ui("Order") }} needs {{ perm("parts_orders.create", "Create parts orders") }}.

{{ shot("parts-row-actions", "Row actions on a part.") }} {% call note("Costs are a separate permission") %} Avg cost, Last price, the inventory totals and the Core Cost / Credit columns appear only with {{ perm("parts.view_costs", "View part costs") }}. Without it the server also strips costs from part search, history and cross references, and the part form has no Average cost field. {% endcall %}

Labor Rates

{% call step(1, "+ Add Labor Rate") %}

Name, code and hourly rate. Defaults seeded for a new shop: Standard $100, After Hours $150.

{{ shot("settings-labor-rate-modal", "Add Labor Rate.", "sm") }} {% endcall %} {% call step(2, "Where rates are used") %}

Picked on every work order labor line (shown as “Name ($X/hr)”) and as each customer's Default Labor Rate. The “standard” rate is also what jobs created by mechanics get automatically.

{% endcall %} {% call step(3, "Edit or delete") %}

Editing a rate changes it for future jobs only — the hourly rate is snapshotted into each work order on save. Delete is soft; old work orders keep their snapshotted rate.

{% endcall %}

Shop Supply Amount

The shop supply percentage (default 5) applied to labor on work orders. It appears on every work order as an editable amount with a reset button, so you can zero it on a specific job.

Core Charge Rules

Charge core by default — whether the Core toggle on work order part lines starts switched on. Off means the shop keeps cores by default and tracks them on the Cores tab.

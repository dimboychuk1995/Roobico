Invite a user

{% call step(1, "+ New user") %}

First / Last name, Email (globally unique), Phone, Role (Manager, Parts manager, Senior mechanic, Mechanic, Viewer, General manager — Owner is not assignable here), Active flag, Pay type (Salary with a weekly amount, or Hourly — hourly rates are set per employee in the uAttend integration) and Shop access checkboxes.

{{ shot("settings-user-create-modal", "Create new user.", "md") }} {% endcall %} {% call step(2, "The invitation") %}

The new user gets an email with an Accept Invitation link (valid 7 days) where they create their own password. Until then they show an orange Invited badge, cannot log in, and have a {{ ui("Resend invite") }} button.

{% endcall %} {% call step(3, "Edit later") %}

{{ ui("Edit") }} opens the same fields plus the Active switch; shop access changes apply immediately.

{{ shot("settings-user-edit-modal", "Edit user.", "md") }} {% endcall %} {% call warn("Passwords are strictly personal") %} Neither the owner nor managers can set or change another user's password anywhere. Forgotten password → the user resets it from the login page. Re-hiring a deactivated user goes through a fresh invitation (the old password is cleared). {% endcall %}

Per-user permissions

{{ ui("Permissions") }} on a row: the role provides a baseline; Allow grants extra permissions on top, Deny removes them. Deny always wins. Changes apply immediately. Nobody can change their own overrides, and you can only grant permissions you have yourself.

{{ shot("settings-user-permissions-modal", "Per-user permissions with Allow / Deny overrides.", "md") }}

Deactivate and re-hire

  • {{ ui("Deactivate") }} blocks login but keeps history; you cannot deactivate yourself. Deactivated users leave the default list — switch the status filter to Inactive users / All users; each inactive row has {{ ui("Activate") }}.
  • Creating a user with the email of a deactivated user of your company reactivates that user with the data you enter (a fresh profile). An email of an active user, or of another company, is refused.

Rules worth knowing

  • You can assign only a role whose permissions you have yourself (the Owner can assign any role).
  • Only an Owner can edit, deactivate or re-assign the role of another owner account.
  • Pay type / Salary amount are visible and saved only with {{ perm("settings.manage_pay", "Edit employees' pay type & salary") }}; nobody can change their own pay.
{% call note("Mechanic roles and billing") %} Users with the Mechanic or Senior mechanic role work in no-price mechanic mode and are billed per mechanic; other roles are “full users”. Deactivated staff is free. See {{ lesson_link("settings/billing") }}. {% endcall %}

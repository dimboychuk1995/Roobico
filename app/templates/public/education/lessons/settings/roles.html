System roles

RoleScope
OwnerAlways all permissions; cannot be edited.
General managerEverything except Roobico billing.
ManagerEverything except roles and billing.
Parts managerParts, vendors, parts orders, parts settings, financial reports (no payroll), work orders read-only with costs.
Senior mechanicWork orders, calendar, customers, units and the parts catalog — without any prices; only the Mechanic Hours report.
MechanicMechanic mode: work orders without prices, calendar view, attachments.
ViewerRead-only access to everything with prices, balances, financial reports and the Activity Journal; no create / edit / delete / payment keys.

System roles cannot be deleted; a custom role in use by active users cannot be deleted either.

Keys that decide who sees money

  • {{ perm("work_orders.view_costs", "View part costs inside WO") }} — the master switch. Without it a user with work-order access works in mechanic mode: no prices anywhere, including customer balances, the customer's Payments / Estimates tabs, dashboard money blocks and the WO Cost button.
  • {{ perm("parts.view_costs", "View part costs") }} — the purchase side of the catalog: Avg cost, Last price, inventory totals, Core Cost / Credit, the Average cost field.
  • {{ perm("reports.view_financial", "View financial reports") }} and {{ perm("reports.view_payroll", "View Timecard / Salary report") }} — reports with money and employee pay.
  • {{ perm("settings.manage_pay", "Edit employees' pay type & salary") }} — pay fields in the user form.
{% call note("Every checkbox is enforced by the server") %} Pages render only the buttons a role may use, and the server re-checks each action, so what you see is exactly what you can do — a hand-crafted request gets 403. {% endcall %} {% call tip("Common recipes") %} Bookkeeper: clone Viewer and tick View Timecard / Salary (+ View financial reports). HR who must not see salaries: Manage users without the pay key. An office person who changes nothing: Viewer. {% endcall %}

{{ shot("settings-shops", "The Shops page: shop list, Add shop, timezone for the active shop.") }} {% call step(1, "+ Add shop") %}

Name, email, address, phone, billing address and logo (the logo prints on PDFs when PDF Design says so). A new shop gets its own database with seeded categories, a default pricing scale, labor rates and rules; owners automatically get access.

{{ shot("settings-shop-add-modal", "Add Shop dialog.", "sm") }} {% endcall %} {% call step(2, "Grant access") %}

Settings → Users → edit a user → tick the shop in Shop access. The change applies on their next request — no re-login. Users see only their allowed shops in the top-bar Active shop switcher.

{% endcall %} {% call step(3, "Switch and configure") %}

Pick the new shop in the top bar and set its labor rates, pricing, tax, templates, PDF design and integrations — each shop has its own.

{{ shot("topbar-shop-switcher", "The Active shop switcher.") }} {% endcall %}

Timezone

The Timezone For Active Shop selector on this page decides what “today” means on every list, report and PDF of that shop. Save Timezone after changing it.

Deactivating a shop

{{ ui("Inactive") }} deactivates a location (never deletes it). Inactive shops disappear from the switcher; the data stays. Deactivated locations are not billed.

{% call note("Billing") %} The first active location is free; each additional active location is billed per month — see {{ lesson_link("settings/billing") }}. {% endcall %}

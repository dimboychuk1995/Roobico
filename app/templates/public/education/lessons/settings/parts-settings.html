Parts Categories

Type a name and {{ ui("Add") }}. Categories are a filter and a stocktake scope; Edit renames, Delete removes an unused category. A new shop comes with a seeded set.

Parts Locations

Build the tree up to 4 levels: Warehouse › Rack › Shelf › Bin. Pick the parent and type the new location's name. Each part has one primary location (set in the part form); stock can still sit in several locations at once ({{ lesson_link("parts/locations") }}).

{{ shot("settings-parts-locations", "The Parts Locations tree.", "md") }} {% call note("Deleting a location") %} Not possible while it has sub-locations, is the primary location of a part, or still holds stock — transfer the stock out first. {% endcall %} {% call tip("Name locations the way the shelf is labeled") %} Receiving asks where to put each line and stocktakes can be scoped to a location — short, physical names (A-3, Bin 12) make both faster. {% endcall %}

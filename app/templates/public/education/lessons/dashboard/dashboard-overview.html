Sidebar → {{ ui("Dashboard") }}. The dashboard is a summary of the active shop for the selected period (default This Month).

{{ shot("dashboard-overview", "The dashboard for a period: money cards, donuts, goals and the hours chart.") }}

Period filter and quick actions

The date presets are the same as in reports: Today, Yesterday, This Week, Last Week, This Month, Last Month, This Quarter, Last Quarter, This Year, Last Year, All Time, or a custom range. {{ ui("Reset") }} returns to the default.

{{ shot("dashboard-filters", "Date presets and the custom range.") }}

Quick actions open the right form in one click: {{ ui("Create WO") }}, {{ ui("Create PO") }}, {{ ui("New Customer") }}, {{ ui("New Vendor") }}.

{{ shot("dashboard-quick-actions", "Quick actions row.") }}

Widgets

WidgetWhat it shows
Work Orders Paid vs UnpaidA donut with the paid percentage, the number of work orders and the Labor / Parts / Total / Unpaid totals for the period. Estimates are excluded.
Parts Orders: Received vs OrderedReceived % (by count) and paid % (by amount), with Items, Non-inventory and Spend. Orders from email that are still Not confirmed do not count.
Goals ProgressThree rings — Labor, Parts Sales, Total — against the monthly goals set with {{ ui("Edit Goals") }}. Other periods prorate the monthly target by days.
Labor Hours — CumulativeA line chart with up to three running totals: Actual (mechanics' job timers), Invoiced (labor hours billed on work orders) and uAttend (time clock, only when the integration is connected). Below it: totals, Invoiced ÷ Actual, Actual ÷ uAttend and a per-mechanic table.
Outstanding Balance (All Time)The total customers owe you. It ignores the date filter on purpose — a balance is always all-time.
{% call note("Who counts as a mechanic") %} Only users with the Mechanic or Senior mechanic role feed the hours chart. A manager who starts a job timer is ignored; a uAttend employee matched to a manager is excluded too. Hours with no assigned mechanic show as the Unassigned labor row so the table always adds up. {% endcall %}

Who sees what

The money blocks need the permission {{ perm("work_orders.view_costs", "View part costs inside WO") }}. A Senior mechanic with dashboard access sees only the hours chart. Editing goals needs {{ perm("dashboard.edit_goals", "Edit dashboard goals") }}.

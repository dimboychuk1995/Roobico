Open a unit from the customer's Units tab, from global search or from a work order's unit row.

{{ shot("unit-page", "A unit page: header, buttons, inspection card and service history.") }}

Header and buttons

The header shows the unit number, year, make, model and VIN with the customer underneath. Buttons: {{ ui("Files") }} (attachments), {{ ui("Recalls") }}, {{ ui("Annual Inspection") }} and {{ ui("Create Work Order") }} (opens the work order page with the customer and unit preselected).

Work Orders tab — the service history

Every work order ever performed on the unit, with search, date presets and totals (totals only for users who can see prices). {{ ui("Show labor details") }} expands a card per job: description, hours badge, labor total and a parts table with quantity, price, line totals and a parts subtotal. Paid work orders appear to mechanic-mode users as “completed”.

{{ shot("unit-page-labor-details", "Show labor details: jobs with hours and the parts used.") }}

Recalls

{{ ui("Recalls") }} checks NHTSA safety recalls for the unit — it needs Year + Make + Model or a valid VIN. New recalls show a NEW badge. A nightly job also emails customers a digest when new recalls appear for their vehicles, so you do not need to check manually.

{{ shot("unit-recalls-modal", "NHTSA Recalls dialog.", "md") }}

Annual Inspection card

The card shows the unit's latest DOT annual inspection with its Valid until date — an inspection lasts 12 months; the card turns yellow within 30 days of expiry and red once expired. History expands all previous inspections, each with Download PDF; users with {{ perm("work_orders.delete", "Delete work orders") }} can delete a record. The {{ ui("Annual Inspection") }} button creates a new one, prefilled with the VIN and the customer as the carrier.

{{ shot("unit-inspection-modal", "Annual Vehicle Inspection dialog opened from the unit page.", "md") }}

Details tab

Edit the unit's fields, upload attachments, {{ ui("Deactivate Unit") }} / {{ ui("Activate Unit") }}, or create a work order. A unit's mileage can be corrected here if a wrong value was entered on a job.

{{ shot("unit-page-details-tab", "Unit Details tab.") }} {% call tip("Mileage rule") %} A work order updates the unit's odometer only when its mileage is higher than the unit's current value — so correcting an old work order never rolls the unit back. If the unit's mileage itself is wrong, fix it on this tab. {% endcall %}

All three settings live on the customer's Details tab (and the Pricing Scale / Override can be set at creation). They become the defaults for that customer's work orders; a single work order can still override any of them.

{{ shot("customer-page-details-tab", "Details tab with Default Labor Rate, Pricing Scale and the Override switch.") }}

Default Labor Rate

The labor rate preselected on every new labor line of this customer's work orders. It is never empty — if nothing is chosen, the shop default (“Standard”) is used. To give a fleet a lower hourly rate: create the rate in Settings → Work Order Settings → Labor Rates, then pick it here. On any single job you can still choose a different rate in the labor block.

Pricing Scale

{% call step(1, "Create the scale once") %}

Settings → Parts & Pricing → Margin / Markup Rules → {{ ui("New scale") }}. For a flat 20% margin: mode Margin, one rule From 0, To empty, 20. See {{ lesson_link("settings/pricing-scales") }}.

{% endcall %} {% call step(2, "Assign it to the customer") %}

Customer → Details → Pricing Scale → pick the scale → Save. From now on parts on this customer's work orders are priced from average cost through that scale. Everyone else stays on the shop default.

{% endcall %} {% call step(3, "Decide about fixed selling prices") %}

Some parts carry a fixed Selling price that normally wins over any scale. Switch on Override part selling price (“Always use the scale, ignore part's selling price”) if this customer's scale must apply even to those parts. The summary card then shows an Override badge.

{% endcall %}

How a part price is chosen on a work order

  1. Customer has Override part selling price → price is always computed from cost via the customer's scale.
  2. Otherwise the part's fixed Selling price, if it has one.
  3. Otherwise average cost through the scale (margin or markup).

A price typed by hand on the work order line is never overwritten by any of these.

Taxable

Switch Taxable to No for tax-exempt customers. New work orders for them default to non-taxable; the per-work-order Taxable toggle can still override. Tax applies to parts and taxable misc charges only — labor is never taxed.

{% call note("Price did not change after you changed the scale?") %} In order: (1) the part has a fixed Selling price and the customer has no Override; (2) the price was edited by hand on the work order; (3) it came from a service template where it was pinned; (4) the scale is not the one assigned to that customer. {% endcall %}

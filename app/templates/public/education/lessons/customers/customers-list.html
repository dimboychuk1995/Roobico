Search and filter

The search box searches every field: company, contact names, phone, email and address. Next to it is the status filter — Active customers (default), Inactive customers, All customers. The same filter exists on Vendors, Parts, Users and a customer's Units tab.

{{ shot("customers-search-filter", "Search box and the Active / Inactive / All filter.", "md") }}

Columns

ColumnMeaning
CompanyCompany name with the address underneath.
NameThe main contact; a grey Inactive badge marks deactivated customers.
Phone / EmailFrom the main contact — there are no separate customer-level phone or email fields.
Current BalanceWhat the customer owes right now: the sum over active work orders of max(0, total − paid). An overpaid work order never offsets another one. Shown only to users who can see prices.
Actions{{ ui("Open") }} — the customer page.

Permissions behind the buttons

  • {{ ui("Add Customer") }} needs {{ perm("customers.create", "Create customers") }}.
  • Saving the profile needs {{ perm("customers.edit", "Edit customers") }}; {{ ui("Portal Link") }} needs {{ perm("customers.manage_portal", "Manage customer portal links") }}.
  • Balances and all amounts need {{ perm("work_orders.view_costs", "View part costs inside WO") }} — a Senior mechanic sees the customer without money, and paid work orders appear to them as “completed”.

  • One record type for companies and private clients.
  • Contacts and the main contact.
  • Address, the Taxable switch, the Default Labor Rate and the pricing settings you can set at creation.
{% endcall %} {% call step(1, "Click Add Customer") %}

Customers → {{ ui("Add Customer") }} (also reachable from the dashboard quick action New Customer). The dialog opens.

{{ shot("customer-add-modal", "The Add Customer dialog.", "md") }} {% endcall %} {% call step(2, "Company name — or a named contact") %}

The rule is simple: you must enter either a Company Name or at least one contact with a name. A fleet gets a company name; a walk-in private client can be just a contact.

{% endcall %} {% call step(3, "Contacts") %}

Add any number of contacts, each with First / Last Name, Phone and Email. Exactly one is the Main contact — it is shown in tables and preselected as the email recipient for invoices, receipts and approval requests. You can edit contacts later from the Details tab or straight from any email dialog.

{% endcall %} {% call step(4, "Address, Taxable, labor rate, pricing") %}
  • Address is required; start typing and pick a suggestion.
  • Default Labor Rate — the labor rate preselected on every new labor line of this customer's work orders. The shop default (“Standard”) is preselected; pick another one for a fleet with its own hourly rate. Details in {{ lesson_link("customers/customer-pricing") }}; it can be changed later on the Details tab.
  • Taxable — switch it off for tax-exempt customers. It presets the Taxable toggle on their work orders (you can still override per work order). Labor is never taxed for anyone.
  • Pricing Scale and Override part selling price — special parts pricing for this customer; explained in {{ lesson_link("customers/customer-pricing") }}. Leave the defaults if the customer pays list prices.
{{ shot("customer-add-modal-filled", "A company filled in with its address and main contact.", "md") }} {% endcall %} {% call step(5, "Create") %}

Click {{ ui("Create") }}. You are returned to the Customers list with a success message; click the new customer's row to open its page. Next: add units (the vehicles) on the Units tab — see {{ lesson_link("customers/add-unit") }}.

{% endcall %} {% call warn("Duplicates are blocked") %} A customer name that already exists in the shop (case-insensitive) is refused. If the message says the existing record is deactivated, open the list with Inactive customers and activate it instead — its history comes back with it. {% endcall %} {% call note("No notes field") %} There is no free-text notes field on a customer. Use attachments on the customer's Details tab for documents and notes. {% endcall %}

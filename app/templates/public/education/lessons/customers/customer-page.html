Header buttons

  • {{ ui("Back") }} — to the list.
  • {{ ui("History") }} — the Activity Journal filtered to this customer: every edit with who, when and the old / new values.
  • {{ ui("Portal Link") }} — send the customer a read-only portal link ({{ lesson_link("customers/customer-portal") }}).
  • {{ ui("Create Work Order") }} — opens the work order page with this customer preselected.
  • {{ ui("Deactivate Customer") }} / {{ ui("Activate Customer") }} — soft deactivation ({{ lesson_link("customers/deactivate") }}).

Summary card

Company, main contact, address and phone, the Current Balance, and the customer's pricing settings: Default Labor Rate, Pricing Scale and an Override badge when “Override part selling price” is on. Current Balance = the sum over the customer's active work orders of max(0, total − paid); an overpaid work order never offsets another one. Amounts are visible only with {{ perm("work_orders.view_costs", "View part costs inside WO") }}.

Tabs

{% call step(1, "Work Orders") %}

Every work order of the customer with search, the paid-status filter and date presets; footer totals Labor / Parts / Total / Unpaid for the current filter. Click a row to open the work order.

{% endcall %} {% call step(2, "Units") %}

The customer's vehicles with unit number, VIN, year / make / model and mileage. {{ ui("Add Unit") }} creates one; the {{ ui("Inspection") }} button on each row starts a DOT annual inspection for that unit. Use the status filter to see inactive units.

{{ shot("customer-page-units-tab", "Units tab with Add Unit and per-row Inspection buttons.") }} {% endcall %} {% call step(3, "Payments") %}

Payments across all of the customer's work orders; a payment can be deleted here (needs {{ perm("work_orders.manage_payments", "Manage payments") }}).

{{ shot("customer-page-payments-tab", "Payments tab.") }} {% endcall %} {% call step(4, "Estimates") %}

Work orders saved as estimates (quotes) for this customer. Edit opens the estimate page; see {{ lesson_link("work-orders/estimates") }}.

{{ shot("customer-page-estimates-tab", "Estimates tab.") }} {% endcall %} {% call step(5, "Details") %}

The edit form: contacts (one is the main contact), address, Taxable, Default Labor Rate, Pricing Scale, Override part selling price, plus attachments and the Deactivate button. Save needs {{ perm("customers.edit", "Edit customers") }}.

The calendar shows appointments only — a work order is on it when an appointment is linked to it. The rule behind the link is simple: the work order is the source of truth; the calendar never changes a work order.

From appointment to work order

{% call step(1, "Fill the appointment") %}

Customer and unit are required for this; add presets, mechanics and a note if you like.

{% endcall %} {% call step(2, "Press Create Work Order") %}

The appointment is saved first, then the work order page opens in a new tab with everything prefilled: customer, unit, one labor block per preset, all mechanics of the appointment assigned to every block (even split), and the note as the job description — or, when it is long or a preset already named the job, as the block's Describe Issue text that the mechanic sees under the job.

{% endcall %} {% call step(3, "Save the work order") %}

The appointment is now linked: its block carries a WO # badge, and its dialog shows “Linked to WO #…” with the live work-order state (Not started, In progress, Mechanic done, Completed, Paid), the first jobs, {{ ui("Open WO") }} and {{ ui("Unlink") }}.

{{ shot("calendar-appointment-modal", "The appointment dialog — Create Work Order sits in its footer; a linked appointment shows the WO panel at the top.", "md") }} {% endcall %}

Mechanics (mechanic mode) do not get the button: on the phone they press Start work in the appointment and the server builds the work order from its presets, crew and note.

From work order to calendar

On the page of an existing work order press {{ ui("Schedule") }} (next to History / Back). The calendar opens with a new appointment already linked to the WO and prefilled from it: customer, unit, the mechanics of its labor blocks, the first jobs as the title and the planned hours as the duration (today at 08:00 — set the real date and time, then Save). A work order can have several appointments, for example two visits. The Scheduled card at the top of the WO page lists every live (not cancelled) appointment — date, time, mechanics, presets, note — with an Open calendar link.

What follows the work order

  • Status — when a mechanic starts a timer on the WO (or takes it into work from the phone) the appointment turns In Progress; when the mechanic presses Done, or the WO is completed or paid by any route, it turns Completed. The status never goes back by itself — if a job is reopened, set the appointment by hand. A Cancelled appointment is never touched. (If your shop replaced the built-in statuses, the sync has nothing to set and leaves the appointment alone.)
  • Customer and unit — a Transfer or a unit change on the work order moves the appointment along. In the dialog these two fields are read-only while linked: “Customer and unit come from WO #… — change them there or unlink”.

What the calendar never changes

  • Moving an appointment to another mechanic or time does not reassign anyone on the work order.
  • Reassigning a mechanic in the WO's labor blocks does not move its appointments — drag them yourself.
  • The status buttons in the appointment do not change the work order's status.
  • {{ ui("Unlink") }} clears the link and nothing else. Deleting the work order does the same for all its appointments — they stay on the grid with their status.

Sidebar → {{ ui("Calendar") }} — the shop's schedule and its activity log in one grid (Mon–Sun, 06:00–21:00, 15-minute steps). Needs {{ perm("calendar.view", "View calendar") }}.

{{ shot("calendar-week", "The week view.") }}

Two kinds of blocks

  • Appointments — what you planned by hand. Click an empty slot to create one, click a block to edit, drag & drop to move. See {{ lesson_link("calendar/appointments") }}.
  • Work orders — every active work order appears automatically, even if nobody scheduled it, so you can see who did what, when, and what is still waiting. A WO block has a left edge in the mechanic's color, their initials in the corner and a status chip. See {{ lesson_link("calendar/wo-on-calendar") }}.

Colors

ChipMeaning
Not startedThe work order exists, no mechanic has started it.
In progressA mechanic is working on it — a pulsing chip means a timer is running right now.
Mechanic doneAll mechanics pressed Done; the manager has not reviewed it yet.
CompletedWork finished, payment pending.
PaidInvoice paid. Mechanic-mode users see it as Completed.

Estimates are not shown — they are quotes, not work. The legend under the toolbar explains the colors.

Who is who

Every mechanic has a color. The row of markers on top (color, initials, name) is the key; each block carries the same color on its left edge and the initials in its corner. Click a marker to show only that mechanic; click again to show everyone.

Toolbar

  • {{ ui("‹") }} {{ ui("Today") }} {{ ui("›") }} — move by week (or by day in the By mechanic view).
  • {{ ui("Week") }} — the classic 7-day grid; inside each day every mechanic with blocks gets their own narrow lane. Click a day header to expand that day into one lane per mechanic; click again to make it wider; a third time returns to normal.
  • {{ ui("By mechanic") }} — one day, a column per mechanic plus Unassigned ({{ lesson_link("calendar/by-mechanic") }}).
  • All mechanics dropdown — show one mechanic or only unassigned blocks.
  • Work orders switch — hide the automatic WO blocks and keep only appointments; remembered in this browser.
  • ⚙ — calendar settings: appointment statuses and colors.

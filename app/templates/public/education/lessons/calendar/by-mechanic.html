Toolbar → {{ ui("By mechanic") }} (or click a day header in Week view). One day, a column per mechanic of the shop plus Unassigned; ‹ › move by day, the date box jumps to a date.

{{ shot("calendar-by-mechanic", "The By mechanic view: one column per mechanic, Unassigned on the right, a counter in each header.") }}
  • Each header shows the mechanic's colour dot, name and how many live (not cancelled) appointments they have that day.
  • A crew appointment (several mechanics) appears in each of their columns.
  • The Unassigned column is your to-do list: jobs nobody is on yet.
  • The All mechanics dropdown narrows the view to one column — and works in Week view too.

Plan a job for a mechanic

{% call step(1, "Click inside the mechanic's column") %}

The appointment dialog opens with the mechanic already chosen and the time you clicked (snapped to 15 minutes, one hour long). Add customer, unit, presets and the note. Save.

{% endcall %} {% call step(2, "Move jobs between mechanics by dragging") %}

Drag a block into another column: a one-mechanic plan simply gets that mechanic; for a crew, the member whose column you dragged out of is swapped for the new one and the rest stay; dropping on Unassigned removes the mechanics. Dragging up or down changes the time at the same time; Esc cancels.

{% endcall %} {% call step(3, "Keep the day readable") %}

Two blocks at the same time in one column sit side by side — a double booking you can see at a glance. Shorten one by its bottom edge, move it, or give it to someone else. Cancelled jobs stay faded in the column and are not counted in the header.

{% endcall %} {% call note("The work order stays as it is") %} Moving an appointment to another mechanic changes the appointment only. If the job is linked to a work order and really changed hands, reassign the mechanic in the work order's labor block as well ({{ lesson_link("work-orders/assign-mechanics") }}). {% endcall %}

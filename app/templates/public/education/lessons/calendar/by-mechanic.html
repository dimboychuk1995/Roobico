Toolbar → {{ ui("By mechanic") }}. One day, a column per mechanic plus Unassigned; ‹ › move by day.

{{ shot("calendar-by-mechanic", "The By mechanic view.") }}
  • Each header shows how many different jobs (work orders / appointments) the mechanic has that day — several timer sessions on one work order count once.
  • A work order with several mechanics appears in each of their columns.
  • Dragging a block into another column reassigns the mechanic of that appointment.
  • The All mechanics dropdown narrows the view to one person or to unassigned blocks only.

Plan a job for a mechanic

{% call step(1, "Click inside the mechanic's column") %}

The appointment dialog opens with the mechanic preselected. Add customer, unit, presets and the time. Save.

{% endcall %} {% call step(2, "Or drag a chip") %}

Drag a work order chip from the Not scheduled strip into the mechanic's column: a linked appointment is created for that mechanic at that time.

{% endcall %} {% call step(3, "Watch the day unfold") %}

When the mechanic starts the timer, the actual block appears in their column and the plan steps aside. A plan that overlaps someone's real work on a different job is flagged with a red !.

{% endcall %} {% call tip("Week view can do this too") %} In the week view, click a day header to expand that day into one lane per mechanic — dropping a chip into a lane assigns that mechanic, same as here. {% endcall %}

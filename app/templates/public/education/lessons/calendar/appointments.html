{% endcall %} {% call step(1, "Click an empty slot") %}

In Week view click the day column at the start time; in By mechanic click inside the mechanic's column — that assigns the mechanic. The start snaps to 15 minutes and the end is set one hour later. Needs {{ perm("calendar.create", "Create appointments") }}.

{% endcall %} {% call step(2, "Fill the dialog") %}
  • Customer — type to search; optional. Unit opens once a customer is chosen and searches by number, make/model and VIN.
  • Service presets — one or several tags; they become labor blocks when you create a work order from the appointment.
  • Mechanics — one or several tags; leave empty for Unassigned.
  • When — the day, the start time and the length, set with buttons (see the next step). On a computer screen it is the right half of the dialog, next to the customer and the mechanics.
  • Status — one button per status; the chosen one is filled with its colour.
  • Title / note — the free text shown in bold on the block: phone number, job list, anything the mechanic should know (up to 500 characters).
{{ shot("calendar-appointment-modal", "The appointment dialog: customer, unit, presets and mechanics on the left, the When block with the day, start-time and length buttons on the right, status buttons and title / note below.", "lg") }} {% endcall %} {% call step(3, "Set the day and the time with the buttons") %}

The When block replaces typing a time. The line at its top right always says what will be saved — “Wed, Nov 25 · 10:30 – 12:30 · 2 h”.

  • Day — {{ ui("Today") }}, {{ ui("Tomorrow") }} and the next five days as buttons; for any other date use the small date box on the right.
  • Start time — one large button per working hour. For a start that is not on the hour press {{ ui(":15") }}, {{ ui(":30") }} or {{ ui(":45") }} and the hour buttons read 08:30, 09:30 … {{ ui("Earlier / later hours") }} shows all 24 hours.
  • Length — 30 min to 8 h; the end follows the start, so changing the hour keeps the length. {{ ui("Other…") }} opens Ends at for an exact end (15-minute steps, up to 24:00). One appointment stays within one day.

An orange dot on an hour button means a chosen mechanic is already booked in that hour — hover it to see the appointment. It is only a warning: the button works, and a hint under the fields repeats it. Press {{ ui("Save") }}.

{% call warn("No start time — no Save") %} A slot you clicked on the grid already carries its time. An appointment opened without one — the + of a By status column, or {{ ui("Schedule") }} on a work order — shows “choose a start time” in red, and Save answers “Choose the start time — press one of the time buttons.” until you press an hour. The calendar asks instead of quietly saving a time nobody chose. {% endcall %} {% endcall %} {% call step(4, "Edit, move, resize") %}

Click a block to open the same dialog (needs {{ perm("calendar.edit", "Edit appointments") }}; without it the dialog is read-only). Drag a block to another time, another day (Week) or another mechanic's column (By mechanic) — it snaps to 15 minutes; Esc cancels. Drag the bottom edge to make it longer or shorter (at least 15 minutes).

{% endcall %} {% call step(5, "Cancel or delete") %}

A customer called off? Set the status to Cancelled — the block stays on the grid, faded and struck through, so the day still tells its story. {{ ui("Delete") }} in the dialog removes the record for good (needs {{ perm("calendar.delete", "Delete appointments") }}).

{% endcall %}

Statuses and working hours

Scheduled, Confirmed, In Progress, Completed and Cancelled come out of the box. ⚙ → Calendar settings (needs {{ perm("calendar.manage_settings", "Manage calendar settings") }}) lets you rename and recolour them and add your own (“Waiting for parts”, “Warning”). Scheduled, In Progress, Completed and Cancelled show a lock and cannot be removed — the work-order link uses them. Working hours set the first and last hour of the grid; anything planned outside them is still shown, the grid simply grows.

The calendar never refuses it; the blocks are drawn side by side so the clash is visible, and you decide: move one, shorten it, or hand it to someone else. {% endcall %} {% call tip("Turn the plan into a work order") %} Fill customer and unit, then press {{ ui("Create Work Order") }} in the dialog — the work order page opens with everything prefilled and the appointment is linked to it.

{% endcall %} {% call step(1, "Click an empty slot") %}

In Week view click the day column at the start time; in By mechanic click inside the mechanic's column — that assigns the mechanic. The start snaps to 15 minutes and the end is set one hour later. Needs {{ perm("calendar.create", "Create appointments") }}.

{% endcall %} {% call step(2, "Fill the dialog") %}
  • Customer — type to search; optional. Unit opens once a customer is chosen and searches by number, make/model and VIN.
  • Service presets — one or several tags; they become labor blocks when you create a work order from the appointment.
  • Date, Start, End — 15-minute steps (End also offers 24:00); changing Start keeps the duration. One appointment stays within one day.
  • Mechanics — one or several tags; leave empty for Unassigned.
  • Status — one button per status; the chosen one is filled with its colour.
  • Title / note — the free text shown in bold on the block: phone number, job list, anything the mechanic should know (up to 500 characters).

If a chosen mechanic already has an appointment at that time a small hint appears — information only, Save still works. Press {{ ui("Save") }}.

{{ shot("calendar-appointment-modal", "The appointment dialog: customer, unit, presets, date and time, mechanics, status buttons, title / note.", "md") }} {% endcall %} {% call step(3, "Edit, move, resize") %}

Click a block to open the same dialog (needs {{ perm("calendar.edit", "Edit appointments") }}; without it the dialog is read-only). Drag a block to another time, another day (Week) or another mechanic's column (By mechanic) — it snaps to 15 minutes; Esc cancels. Drag the bottom edge to make it longer or shorter (at least 15 minutes).

{% endcall %} {% call step(4, "Cancel or delete") %}

A customer called off? Set the status to Cancelled — the block stays on the grid, faded and struck through, so the day still tells its story. {{ ui("Delete") }} in the dialog removes the record for good (needs {{ perm("calendar.delete", "Delete appointments") }}).

{% endcall %}

Statuses and working hours

Scheduled, Confirmed, In Progress, Completed and Cancelled come out of the box. ⚙ → Calendar settings (needs {{ perm("calendar.manage_settings", "Manage calendar settings") }}) lets you rename and recolour them and add your own (“Waiting for parts”, “Warning”). Scheduled, In Progress, Completed and Cancelled show a lock and cannot be removed — the work-order link uses them. Working hours set the first and last hour of the grid; anything planned outside them is still shown, the grid simply grows.
